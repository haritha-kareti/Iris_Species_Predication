<h1 align="center">🌸 Iris Species Prediction Web App</h1>

<p align="center">
  A simple and interactive <b>Machine Learning web application</b> to predict Iris flower species.
</p>

<hr>

<h2>📌 About the Project</h2>

<p>
This application classifies Iris flowers into three categories:
</p>

<ul>
  <li>🌼 <b>Setosa</b></li>
  <li>🌸 <b>Versicolor</b></li>
  <li>🌺 <b>Virginica</b></li>
</ul>

<p><b>Input Features:</b></p>
<ul>
  <li>Sepal Length</li>
  <li>Sepal Width</li>
  <li>Petal Length</li>
  <li>Petal Width</li>
</ul>

<p>
The project demonstrates how machine learning models can be integrated into a web application 
to provide real-time predictions based on user input.
</p>

<hr>

<h2>🧠 Models Used</h2>

<ul>
  <li>✅ K-Nearest Neighbors (KNN)</li>
  <li>✅ Naive Bayes (NB)</li>
</ul>

<p>
These models are trained on the famous Iris dataset and evaluated for accuracy and performance.
</p>

<hr>

<h2>⚙️ How It Works</h2>

<ol>
  <li>User enters flower measurements</li>
  <li>Selects a model (KNN or NB)</li>
  <li>Clicks <b>Predict</b></li>
  <li>Model processes input</li>
  <li>Displays prediction and performance metrics</li>
</ol>

<hr>

<h2>✨ Features</h2>

<ul>
  <li>✔ Simple and user-friendly interface</li>
  <li>✔ Real-time prediction</li>
  <li>✔ Model selection option</li>
  <li>✔ Accuracy display</li>
  <li>✔ Confusion matrix</li>
  <li>✔ Classification report</li>
</ul>

<h2>📊 Dataset Information</h2>

<p>
This project uses the <b>Iris dataset</b>, a well-known dataset in machine learning.
</p>

<ul>
  <li>150 samples</li>
  <li>3 classes (Setosa, Versicolor, Virginica)</li>
